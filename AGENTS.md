# Agent Instructions

These instructions apply to every AI agent working in this repository.

[README.md](README.md) gives an overview of the repository. Each part has its own README: [backend/README.md](backend/README.md) and [frontend/README.md](frontend/README.md).

## Writing code

Before writing or changing any code, read [docs/CODING_STANDARDS.md](docs/CODING_STANDARDS.md) and follow it exactly. It is binding for every contributor, human or AI. If a task seems to need breaking one of its rules, stop and ask instead of improvising.

## Reviewing code

When asked to review code, follow [docs/REVIEW.md](docs/REVIEW.md). It says which branches to compare and how to report findings. Review against [docs/CODING_STANDARDS.md](docs/CODING_STANDARDS.md).

## Raising a pull request

When raising a pull request, fill in the body using [docs/PULL_REQUEST_TEMPLATE.md](docs/PULL_REQUEST_TEMPLATE.md). Keep every section, and write "None" or "Not applicable" instead of deleting one.
